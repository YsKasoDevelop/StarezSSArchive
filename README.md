# スタレゾ SS アーカイブ

保存済みPNGを監視し、ローカルのReal-ESRGANエンジンで高画質化・原本保存するWindows向け非公式ファンツールです。ゲームの権利者による承認・提携・保証はありません。

## 公開用パッケージ

配布ZIPをすべて展開し、`StarezSSArchive.exe` を起動してください。.NETは同梱しているため、別途インストールは不要です。初回に利用条件を確認し「同意してセットアップ」を押すと、AI処理用ファイルを公式GitHubから自動取得します。写真は外部へ送信しません。導入方法は [かんたん説明書](docs/USER_GUIDE.md) にあります。

## ビルド

.NET 8 SDKをインストールし、PowerShellで `./build.ps1` を実行してください。毎回新しい `dist` 配下のフォルダへ、Windows x64向けの.NET同梱版を出力します。

配布物にAIエンジン・AIモデル・ゲーム画像は含めません。初回取得にはインターネット接続、AI処理にはVulkan対応GPUとドライバーが必要です。署名されていない個人制作アプリのため、Windowsの警告が表示される場合があります。取得元を確認し、セキュリティ機能を無効化しないでください。
