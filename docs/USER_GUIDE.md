# スタレゾ SS アーカイブ かんたん説明書

本アプリは非公式ファンツールです。ゲームの権利者とは提携・承認関係がありません。この公開版の説明書にはゲーム画像を使用していません。

## 初回の準備

1. 配布ZIPをダウンロードして「すべて展開」します。
2. 展開先の `StarezSSArchive.exe` をダブルクリックします。EXEだけを別の場所へ移さないでください。
3. 利用条件を確認して同意した後、「同意してセットアップ」を押します。AI処理用の公式配布物を自動取得・検証します。
4. 起動後、タスクトレイのアイコンから設定を確認します。

.NETの手動インストールやAIファイルの手作業での配置は不要です。初回のみインターネット接続が必要です。取得に失敗した場合は接続を確認して再試行できます。閉じるボタンでキャンセルできます。AIファイルは `%LOCALAPPDATA%\StarezSSArchive\engine-20220424` に保存します。画像処理はPC内で行い、写真を送信しません。取得元: https://github.com/xinntao/Real-ESRGAN/releases/tag/v0.2.5.0

## 設定と使い方

起動後はタスクトレイのアイコンを右クリックし「設定」を開きます。最初はコピーしたPNGで、監視先・原本保存先・バックアップ保存先を確認してください。これらのフォルダは互いに重ならない場所を指定します。

監視先の初期値は `%USERPROFILE%\AppData\LocalLow\bokura\StarASIA\OriginalPhoto` です。原本とバックアップの初期保存先はピクチャ内の `StarASIA`、それがなく `StarASIA_STEAM` がある場合はそちらの配下です。既存の設定は維持されます。

PNGの書き込み完了後に処理が始まります。内部4倍超解像後、元と同じピクセル寸法で保存します。処理前の画像は設定した `original` 保存先に保持され、監視先には処理後の同名画像が置かれます。監視先のPNGが100枚を超えると古い画像を `backup` 保存先へ退避します。

TTAは初期値OFFです。ONにすると処理時間が増えます。AIは細い模様や輪郭を変える場合があり、失われた情報を正確に復元する保証はありません。

「一時停止」で新しい処理を止め、「再開」で未処理画像を再確認します。レタッチOFF時は新たな画像処理を停止します。「終了」は処理中の画像があれば最大30秒待ちます。設定でWindowsログオン時の自動起動も変更できます。

## 処理できない場合

- 配布ZIPをすべて展開し、ファイル一式が揃っているか確認します。
- 初回セットアップが完了しているか、GitHubへの接続が制限されていないか確認します。
- Vulkan対応GPUとドライバーが必要です。
- 監視先、レタッチON、PNG保存完了を確認します。
- ログは `%LOCALAPPDATA%\StarezSSArchive\app.log`、設定は同じ場所の `settings.json` です。
